# Spike Burst

A geometry nodes VFX: a dome of jagged spikes that bursts out and keeps evolving, for a Niagara mesh flipbook.

## Use it

1. Open `SpikeBurst.lila` and press play (27 frames at 30 fps).
2. Send it to Unreal: select `SpikeBurst`, File > Export Mesh Sequence..., then Send to Unreal. Or map it once so every save updates Unreal:

```python
ops.unrealMap("SpikeBurst", kind="meshSequence", contentPath="/Game/VFX/SpikeBurst/SM_Spike",
              sequence={"scale": 0.1}, niagaraSystem="/Game/VFX/NS_SpikeBurst")
```

Each frame becomes `SM_Spike_000`, `SM_Spike_001`, ... and the Niagara system's mesh renderer gets them in order. The red vertex colour runs from 0 at the origin to 1 at Gradient Length, for fading in the material.

To export files instead: `ops.exportMeshSequence("SpikeBurst", playbackRange=True, scale=0.1, folder="...", pattern="spike_{index}", padding=3)`.

## Troubleshooting

- Nothing moves: the burst is keyed on the modifier's Growth and Evolution; check the time slider is inside frames 0 to 26.
- Spikes too long or too many: see Tune it.
- `SpikeBurst.lila` is generated by `build_spike_burst.py`; rerun it to rebuild the scene and `SpikeBurstFX.lilanodes`.

## Tune it

The modifier shows the group's parameters, grouped by panel:

- Animation: Growth (key 0 to 1 for the burst), Evolution (key it so the spikes change shape).
- Spikes: Spike Length, Density, Sharpness (higher keeps fewer, thinner needles), Randomness, Base Spikes (length at the base relative to the top).
- Colour: Gradient Length.

Share the effect by giving someone `SpikeBurstFX.lilanodes` (Node Editor > Import, or `ops.gnImportGroup(path)`) and applying it to any mesh.
