# Curves

One live, labelled setup per group of curve tools, in a 4 by 3 grid. Every result keeps its history, so editing a curve updates what was built from it.

## Use it

1. Open `curves.lila`.
2. Each setup is a group named `<Setup>Example` with a camera `Cam_<Setup>` framing it; `Cam_All` frames the whole grid at 16:9. Select a camera and use the view's Panels > Look Through Selected, or MMB-drag it from the outliner onto a view.

| Setup | Shows |
| --- | --- |
| Overview | A desk lamp built only from curves: revolved base and shade, piped arm, cable |
| Surfaces | Sweep, revolve and loft |
| NetworkAndBlend | A curve network surface, and a border blend bridging two planes |
| AlongCurve | Rails deformed along curves, posts arrayed along the same path |
| Planar | Text curves and a curve boolean, each with a Bevel Plus solid below |
| Roof | A roof on an L-shaped footprint with a courtyard |
| Blend | A G2 blend between two curves, curvature combs on |
| Cables | A cable bundle sagging between poles and draped over a crate |
| Sketch | A bracket with sketch constraints and dimensions (open the Sketch Tool on it to see them) |
| Groom | Guides combed on a scalp, and hair cards built from them |
| UnrealSpline | A curve mapped to Unreal as a spline actor with a road mesh along it |

## Troubleshooting

- The Overview's profile and path curves are hidden; unhide them to edit the lamp.
- `curves.lila` is generated by `build_curves.py`; rerun it (`lilabatch --batch build_curves.py`) to rebuild the scene.
